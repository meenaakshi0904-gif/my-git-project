AWS EC2 Virtual Machine Project

Study and Practical Implementation of Launching a Virtual Machine

About the Project

This project demonstrates the practical implementation of Amazon Elastic Compute Cloud (AWS EC2). An EC2 virtual machine was created, configured and accessed remotely using SSH.

The project helps in understanding cloud computing, virtual machines, security groups, key pairs and remote server management.

Steps to Launch EC2 Instance

  1. Sign in to the AWS Management Console.
  2. Open the Amazon EC2 service.
  3. Click on Launch Instance.
  4. Select Amazon Linux 2023 as the AMI.
  5. Select the t3.micro instance type.
  6. Create or select the required key pair.
  7. Configure the security group and allow SSH through port 22.
  8. Configure the required storage.
  9. Review the configuration.
  10. Launch the EC2 instance.
  11. Verify that the instance is running.

SSH Connection

The EC2 instance was accessed remotely from a Windows computer using SSH. The private key and public DNS of the EC2 instance were used for secure authentication.

Successful connection to the EC2 instance confirmed that the virtual machine was running correctly.
